# Security

This candidate uses one enrolled owner, signed sessions, same-origin checks, scoped agent credentials and private socket separation. Host root, Docker administrators and the authorized agent execution environment remain trusted. Direct agent commits rely on conversational assent reported by the agent.

Before public release, configure a private vulnerability-reporting destination and review dependency/image updates. Report potential vulnerabilities privately to the project maintainer; avoid posting private records or credentials in public issues. Current release gates are in docs/RELEASE-GATES.md.
