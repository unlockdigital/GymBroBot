# Project history

The original private GitHub repository was created on March 11, 2026. GymBroBot developed there as a personally used training application, including a Telegram interface and a standalone workout experience.

The public core is a reviewed extraction and continuation of that application. Its fresh source history establishes the publication boundary. Older operational commits, personal training context and private integration records remain in the private development archive.

The October 2026 release preparation added standalone owner enrollment/recovery, a detailed agent proposal contract, an expandable exercise catalog, per-set prescriptions, owner-scoped private-plan compatibility, assisted-load handling and supported Linux build/recovery tests. Synthetic browser workflows and isolated private-copy rehearsals inform the core's regression suite.

Public release notes will record verified user-facing changes and the exact source/image tested. Additional historical snapshots may be included only after their content, metadata, attribution and redistribution rights pass the same publication review.
